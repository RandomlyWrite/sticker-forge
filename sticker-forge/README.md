# Sticker Forge

A clean, modular Python framework for turning green-screen animations into Telegram sticker sets.

## Features
- Theme system (default + degen + easy to add more)
- Prompt builder with technical rules
- FFmpeg-based video processor
- Batch processing
- Telegram auto-uploader (with optional savage commentary)

## Quick Start

```bash
git clone https://github.com/RandomlyWrite/sticker-forge.git
cd sticker-forge
pip install -r requirements.txt
